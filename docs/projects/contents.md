## 1. League of Legends 커뮤니케이션 패턴 및 소셜 네트워크 분석 (SNA)
> **RoBERTa 기반 언어 모델 및 소셜 네트워크 분석(SNA)을 활용한 게임 내 커뮤니케이션 패턴 연구**

- **진행 기간**: 2023.09 – 2025.09
- **핵심 역할**: 데이터 수집·동기화 파이프라인 설계, 멀티모달 데이터 정합, NLP 감성·의도 분류, 네트워크 그래프 모델링

### 📌 주요 수행 내용 및 아키텍처
1. **API 스키마 분석 및 데이터 수집 파이프라인 구축**
   - Riot Games / LoL Client API 데이터 스키마를 분석하여 인게임 이벤트 로그 수집 파이프라인 설계.
2. **실시간 게임 데이터 로깅 및 이벤트 트리거 알림**
   - 게임의 시작과 종료 시점을 실시간으로 탐지.
   - 모든 인게임 로그를 **Unix Timestamp** 기준으로 밀리초 단위 정밀 기록.
   - 게임 종료 감지 시 데이터 검증 후 **Gmail API**를 통해 리포트 자동 발송 파이프라인 구현.
3. **Discord Voice Data 수집 및 멀티모달 Sync Alignment (보간법)**
   - 커스텀 **Discord Bot**을 개발하여 팀 보이스 오디오 스트림 수집.
   - 녹음 시작점 및 Stop 트리거를 Unix Timestamp로 동기화.
   - 서로 샘플링 레이트와 수집 주기가 다른 게임 로그와 음성 데이터(Text 변환본)의 타임라인을 **보간법(Interpolation)**을 적용해 정밀 정렬(Alignment).
4. **RoBERTa 임베딩 & 소셜 네트워크 분석(SNA) 모델링**
   - 보이스·채팅 텍스트 데이터를 RoBERTa 모델로 감성 및 전략적 의도 매핑.
   - 플레이어를 **Node**, 커뮤니케이션 빈도/감성/영향력을 **Edge Weight**로 정의한 동적 네트워크 그래프 생성.
   - 주요 인게임 이벤트(오브젝트 한타, 갱킹, 킬/데스) 발생 시점의 커뮤니케이션 패턴 및 정보 전파 양상 규명.

## 2. Unknown Project 테스트 지원 도구 개발 (QA/Test Support Tool)
> **신규 프로젝트의 검증 효율 극대화를 위한 풀 파이프라인 자동화 및 시각화 도구**

- **진행 기간**: 2025.12 – 진행 중 (ing)
- **핵심 역할**: 테스트 자동화 툴 개발, 스키마 검증 엔진 설계, 영상-로그 동기화 뷰어 및 DB 탭 구현

### 📌 주요 기능 및 성과
- **데이터 스키마 기반 Log Data 자동 검증/분석**
  - 사전에 정의된 데이터 스키마를 바탕으로 수집된 로그의 결측, 포맷 오류, 런타임 이상치를 자동 탐지/검증.
- **영상 녹화 - 데이터 다운로드 - 자동화 검증 원클릭 파이프라인**
  - 클라이언트 플레이 영상 녹화 종료와 동시에 관련 인게임 로그/서버 데이터를 자동 다운로드하고 즉각 유효성을 검증하는 일원화 프로세스 구축.
- **영상 & 로그 대조 시각화 (Interactive Visualizer)**
  - 로그 타임라인과 플레이 영상을 상호 매핑하여, 특정 오류 로그 발생 프레임으로 즉각 이동할 수 있는 대조 편의 기능 제공.
- **선수 추천 기능 검증 전용 탭 & 실시간 DB 연동**
  - 추천 알고리즘의 Output과 DB 실제 저장 데이터를 한눈에 대조할 수 있는 전용 UI 탭 개발로 QA 검증 속도 대폭 단축.
- **자동화 테스트 결과 - 이슈 티켓 매핑 시스템**
  - 실패한 테스트 케이스 및 에러 패턴을 지라(Jira) 등 이슈 티켓과 자동 매칭하여 중복 버그 리포트를 방지하고 원인 분석 속도 가속화.

## 4. NIES Letter Counter (개선 버전)
> **실시간 바이트/글자 수 측정 및 엑셀 기반 중복 문장 정밀 탐지 텍스트 유틸리티**

- **진행 기간**: 고도화 완료 및 유지보수
- **핵심 역할**: 유틸리티 로직 설계, 엑셀 파서 연동, 실시간 텍스트 차분(Diff) 감지

### 📌 핵심 기능
- **정밀 글자 수 및 Byte 계산**
  - 공백 포함/제외 글자 수, UTF-8 및 EUC-KR 기반의 Byte 수를 입력 즉시 실시간 계산.
- **Excel 파일 연동 중복 문장 탐지**
  - 업로드된 엑셀 시트 내 모든 행(Row)을 파싱하여, 현재 작성 중인 내용과 일치/유사한 문장이 **몇 번 행(Row)과 중복되는지** 직관적으로 명시.
- **실시간 양방향 수정 및 즉시 저장**
  - 중복 발생 위치와 글자 수/Byte 변동 사항을 즉각 확인하며 인라인으로 수정하고 엑셀 형식으로 바로 덮어쓰기/저장할 수 있는 워크플로우 지원.
